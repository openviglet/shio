shio diff --site <name> - compare what a replica serves with what declared it

Walks the capture's pages, asks the instance for each one, and reads the served bytes with
the same scanner the capture used. What comes back is not pixels: the counts the source
recorded against the counts the page shows, per page and per fact.

Exits 1 when a page lost something; a fact the replica GAINED is never a failure.

A page composed from the section vocabulary drops the source's nav, favicon and stylesheet
by design, so the capture's counts are not a claim about it. --mode says what they ARE a
claim about, and defaults to reading it off the conversion plan.

  --site <name>        The site the replica lives in (required)
  --against <what>     Which declaration to judge against (default: capture)
                       capture  - the served page against what the source declared
                       proposal - the content the instance holds against what the plan
                                  said the conversion would make. Reads documents, not
                                  the wire
                       published - the draft against what is live: which fields would
                                  change if you published now. Needs no capture and no
                                  plan
  --address <address>  Narrow --against published to these posts (repeatable); without
                       it the answer is the site's
  --plan <file>        Read the accepted decisions from somewhere else (--against proposal)
  --proposal <file>    Read the candidates from somewhere else (--against proposal)
  --mode <how>         auto (default), fidelity, mixed or authorable
  --inventory <file>   Read a capture from somewhere else
  --limit <n>          Pages to print
  --json               The comparison as JSON on stdout instead of the report

Examples:
  shio diff --site Acme
  shio diff --site Acme --json
  shio diff --site Acme --against proposal   # did the write make what the plan accepted
  shio diff --site Acme --mode fidelity      # judge every fact, whatever the plan says
  shio diff --site Acme --against published  # what goes live if you publish now
  shio diff --site Acme --against published --address post:Acme/blog/hello-world
