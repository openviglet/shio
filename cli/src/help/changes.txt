shio changes — what changed, with a cursor to resume from

  --since <cursor>     Only what happened after that position ("last" = the last pull's)
  --since-last         Same as --since last
  --cursor             Print only the cursor (SINCE=$(shio changes --cursor))
  --site <name>        Scope to one site
  --limit <n>          Entries to print
  --fields             Name the fields each write changed
  --by <who>           agent, curator, or a session id
  --json               Raw JSON instead of lines (a line per event with --follow)
  --follow             Stay open, printing each change; reconnects without loss
  --base-file <file>   Where the last content pull's position is kept

Examples:
  shio changes --since last
  SINCE=$(shio changes --cursor)
  shio changes --follow --site Blog
  shio changes --since last --by curator
