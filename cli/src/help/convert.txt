shio convert --site <name> - apply the accepted conversion plan as content

Turns the blocks accepted by shio propose --accept into posts, plus the captured theme
and scripts. Running it twice changes nothing.

Every post lands in DRAFT: shio publish --site <name> --all is the step after this one.

  --site <name>        The site to write into (required)
  --create-site        Create the site (blank) if it does not exist, as the first step
  --scratch            With --create-site: declare the site DISPOSABLE
  --annotate           Stamp sh-field on a wholly verbatim page: the source's bytes, editable
  --home <path>        Redirect / to one of the captured pages
  --dry-run            Print the plan the instance would apply, and write nothing
  --check              Plan, and exit non-zero if anything would change
  --out <file>         Write the desired-state document to a file and apply nothing
  --ids                Put object ids on the change rows (off by default)
  --limit <n>          Rows to print
  --inventory <file>   Read a capture from somewhere else
  --assets-dir <dir>   Where the captured bytes are (default shio/assets)
  --json               The document as JSON on stdout instead of the report

Examples:
  shio convert --site Acme --dry-run
  shio convert --site Acme --create-site
  shio convert --site Acme --out conversion.json
  shio convert --site Acme --home /en-us/
