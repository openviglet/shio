shio assets prune — the assets nothing references, and what deleting them would free

Lists the assets no post references and no rendered page loads (a theme's font is loaded),
with the bytes they occupy. A dry run: nothing is deleted.

  --site <name>        Only this site's assets
  --folder <id>        Only this folder's assets
  --json               The set as JSON, for a pipeline
  --dry-run            Accepted and redundant: this command never deletes

Example:
  shio assets prune --dry-run
