shio doctor — can I work here? The readiness facts, in one call

Is the instance up and WHICH BUILD, do the credentials work, is the render model provisioned
and current, which sites exist, is there a local content tree.

`version` says "dev" on any instance not run from a packaged jar — the same string before and
after a rebuild, which is the mode where the instance can lag your tree. Read `built
<instant>` instead; when it is absent the run says so.

  --json               The checks as data instead of the aligned list
  --url <url>          The instance (default $SHIO_URL, else http://localhost:2710)
  --user <name>        Console user (default $SHIO_USER)
  --password <pass>    Console password (default $SHIO_PASSWORD)

Three outcomes: `ok`, `FAIL`, and `??` for a fact an unreachable instance left unanswerable.
Exit 1 on any FAIL; a `??` does not fail — running this with no instance checks your own tree.

Examples:
  shio doctor
  shio doctor --json
