Who owns the reading column
Three pages of one product, drawn twice. The only difference is where the measure is set.
the shell sets it, once main: mx-auto max-w-7xl px-4 py-6 md:px-8 md:py-10
a list page
a detail page
a form page
Every page starts on the same line and ends on the same line. A page that needs a narrower column asks the shell for the variant; it does not set a measure of its own.
the shell sets nothing so each page repeats one, and they disagree
px-6, pb-12
max-w-4xl, px-6
px-8, py-4
Nothing here is wrong on its own screen. The defect only exists between screens, which is why review never catches it: nobody opens two pages side by side.
THE RULE
The shell's main owns the max width, the gutters and the vertical rhythm. A page sets none of the three. This is the cheapest of the four decisions to get right and the most expensive to retrofit, because the fix is a class removed from every page rather than one added to the shell.
THE ONE EXCEPTION
A narrower column for a single-question form is a variant the shell offers by name, so it is set in one place and the same everywhere it is asked for.
