Two routes, no default for either. Anything past them — a tenant, a review count — is the product's.
THE FOOTER IS THE REGION NOBODY DECIDED
AppFooter is exported — a hairline, then the product name, its version and a few links — and it is written mt-auto, so it expects a shell that is a flex column with the main growing. No bento shell mounts one. Either the shell carries a footer for every page or the chrome has none; what must not happen is one page growing its own.
TWO THINGS CALLED A SIDEBAR
The console era's collapses, remembers its width and pushes content, so it needs a provider. The rail does none of that: fixed, one width, hidden below md. "No sidebar provider" is about the shell — a page that needs a secondary column still has one, inside the reading column, owned by that page and scrolling with it.
