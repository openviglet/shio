Each item already carries a revertable flag. This is the surface that lets a curator use it — one item at a time, with the reason stored beside the verdict.
WHAT THIS DECIDES
The verdict and its reason live on the item, not on the run — that is what SH1001 needs to stop review being all-or-nothing, and it is the row SH1002 reads back so an agent can learn a change was held and why. The run keeps one thing of its own: the intent it was given (SH1000), which is what makes twelve diffs reviewable as one decision.
NOT CHOSEN — AN INBOX GROUPED BY PAGE
Rows are addresses with something pending. It suits a curator who owns a section, and it destroys the only context a reviewer has: twelve changes that only make sense as “rename Starter to Solo” arrive as twelve unrelated edits, and the intent has nowhere to attach. Grouping by page is a filter on this screen, not a second screen.
