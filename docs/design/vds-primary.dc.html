HOW
:root { --vg-primary-base: …; --vg-primary-base-dark: …; --vg-primary-foreground-base: …; --vg-primary-foreground-base-dark: …; }
NOT BY SETTING --VG-PRIMARY
A consumer stylesheet imports the preset and then declares its own :root, which lands after the dark block at the same specificity and in no layer. One value set there wins on both grounds, and the dark ground silently takes the light value. The inputs are read per ground, so a product never writes a dark block -- the same shape the accent uses for -text-dark.
The fill carries text, so keep that pair at 4.5:1 on both grounds. A gradient stop at full chroma usually will not; the value is a deeper step than the chip is drawn with.
