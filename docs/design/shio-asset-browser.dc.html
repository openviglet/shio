WHAT THIS DECIDES
Every filter on the toolbar is server-side and paged, including “unused” — which is the one that cannot be computed per row without the reverse index SH1033 says nobody has measured. Drawing it as a filter chip beside the others is the claim that it has to be as cheap as the others, and that is a backend decision the console cannot walk back.
NOT CHOSEN — A PICKER THAT IS NOT A PAGE
Media reachable only as a modal from the File widget. It is what exists, it keeps the library invisible until somebody is already editing a field, and it has no room for where-used, alt-text repair or the reclaim pass. The picker stays — as the same list in a dialog, not as the only way in.
