Getting Started with the Shio Universal Editor

Tutorial Alexandre Oliveira
Learn how to instrument your pages with data-sh-* attributes and enable inline visual editing with Viglet Shio.

The Shio Universal Editor brings the power of visual, in-context editing to any web page. Instead of editing content through a traditional form-based CMS interface, authors can click directly on page elements and modify them inline.

How It Works

The architecture follows the proven pattern established by Adobe's Universal Editor, adapted for Viglet Shio. The key components are:

  • Editor Shell - The Shio Console provides the editing UI with toolbar, properties panel, and device preview.
  • Editor Bridge - A lightweight JavaScript library (shio-editor.js) that runs inside your page, detects editable elements, and communicates with the shell.
  • Data Attributes - HTML attributes (data-sh-*) that mark elements as editable and link them to Shio content.

Instrumenting Your Page

Add the shio-editor.js script to your page and annotate elements with data-sh-resource, data-sh-type, and data-sh-prop attributes. The editor does the rest.
